# REPRODUCE.md: Scientific Reproducibility & Audit Guide

This repository adheres to a strict scientific reproducibility standard:
> **Zero Untracked Numbers Mandate**: No numeric claim, metric, or statistical result may appear in the user interface, API endpoints, or publication manuscript unless it was directly generated by an executable, deterministic script with fixed random seeds.

---

## 1. Quick Start (Master Experiment Runner)

To re-run all benchmark pipelines, re-generate all publication tables (CSV, Markdown, LaTeX), re-render all figures, and audit all outputs:

```bash
# From repository root:
python experiments/run_all.py
```

This single command deterministically executes:
1. `experiments/generate_limitations.py` $\to$ `paper_assets/LIMITATIONS.md` & `limitations.tex`
2. `experiments/run_crop_experiments.py` $\to$ `results/crop_metrics.json`, `Table 1`, `Table 4`, `Figure 1`
3. `experiments/run_forest_experiments.py` $\to$ `results/forest_metrics.json`, `Table 2`, `Figure 2`
4. `experiments/run_heat_experiments.py` $\to$ `results/heat_metrics.json`, `Table 3`, `Figure 3`, `Figure 4`
5. Comprehensive artifact audit across `paper_assets/` and `results/`.

## 4. Individual Module Execution

If you prefer to run experiments modularly:

### A. Limitations Section Generator
Generates the comprehensive, audit-compliant scientific limitations disclosures:
```bash
python experiments/generate_limitations.py
```
- **Outputs**:
  - `paper_assets/LIMITATIONS.md`
  - `paper_assets/limitations.tex`

### B. Crop Vigour Anomaly & Multimodal Fusion (`ml/crop/`)
Trains the fused Sentinel-1 SAR + Sentinel-2 optical autoencoder, evaluates the 5-year climatological NDVI z-score baseline, performs S2-only vs S1-only vs S1+S2 ablations, and computes the 4 label-free unsupervised metrics:
```bash
python experiments/run_crop_experiments.py
```
- **Outputs**:
  - Metrics JSON: `results/crop_metrics.json` (synced to `backend/results/` and `frontend/public/`)
  - Table 1: `paper_assets/tables/table1_crop_metrics.{csv, md, tex}` (Unsupervised validation)
  - Table 1b: `paper_assets/tables/table1b_crop_confusion_matrix.{csv, md, tex}` (Confusion matrix on spatial folds)
  - Table 4: `paper_assets/tables/table4_ablation_summary.{csv, md, tex}` (Modality ablation)
  - Figure 1: `paper_assets/figures/fig1_crop_vigour_anomaly.png` (4-panel vigour graphic)
  - Figure 1b: `paper_assets/figures/fig1b_crop_confusion_matrix.png` (Classification confusion matrices)

### C. Forest Disturbance & Canopy Change Detection (`ml/forest/`)
Loads the Hansen Global Forest Change reference tiles, builds spatial train/val/test splits, trains Torres et al. (2021) Early-Concat U-Net and Multimodal Siamese U-Net, and tests out-of-region generalisation on Hasdeo Arand (*Chhattisgarh, India*):
```bash
python experiments/run_forest_experiments.py
```
- **Outputs**:
  - Metrics JSON: `results/forest_metrics.json` (synced to `backend/results/` and `frontend/public/`)
  - Table 2: `paper_assets/tables/table2_forest_metrics.{csv, md, tex}` (Benchmark comparison)
  - Table 2b: `paper_assets/tables/table2b_forest_confusion_matrix.{csv, md, tex}` (Confusion matrix on test block)
  - Figure 2: `paper_assets/figures/fig2_forest_canopy_disturbance.png` (Model comparison & domain shift)
  - Figure 2b: `paper_assets/figures/fig2b_forest_confusion_matrix.png` (Binary confusion matrices)

### D. Urban Heat Island & Thermal Downscaling (`ml/heat/`)
Calibrates Landsat 8/9 ST_B10 thermal data ($\text{DN} \times 0.00341802 + 149.0 - 273.15$), trains Yao et al. (2020) Random Forest downscaler (30 m to 10 m) with strict spatial split evaluation, computes diurnal/seasonal regimes, and prioritizes Visakhapatnam tree-planting parcels:
```bash
python experiments/run_heat_experiments.py
```
- **Outputs**:
  - Metrics JSON: `results/heat_metrics.json` (synced to `backend/results/` and `frontend/public/`)
  - Table 3: `paper_assets/tables/table3_heat_metrics.{csv, md, tex}`
  - Figure 3: `paper_assets/figures/fig3_urban_heat_downscaling.png`
  - Figure 4: `paper_assets/figures/fig4_model_comparisons.png`

## 6. Scientific Limitations Summary

In accordance with strict honesty guidelines:

1. **Proxy-Based Validation**:
   - In `ml/crop/`, models operate under an unsupervised learning paradigm due to the lack of ground-truth crop-cut yields and pathology surveys.
   - Validation relies on environmental proxies: CHIRPS gridded precipitation deficit ($0.05^\circ \approx 5.5\text{ km}$), Sentinel-1 C-band SAR penetration during monsoon cloud cover, and latent space silhouette/temporal stability.
   - CHIRPS anomalies do not reflect sub-field irrigation, drainage, or localized fertilizer micro-dosing.

2. **Hansen Global Forest Change Reference Label Noise**:
   - In `ml/forest/`, Hansen GFC labels originate from Landsat 30 m imagery. Resampling onto 10 m Sentinel resolution cells introduces sub-pixel edge uncertainty (1 Hansen label governs 9 Sentinel pixels).
   - Hansen annual disturbance layers have temporal attribution lags and miss non-stand-replacing degradation (selective logging, canopy thinning).
   - Out-of-region generalisation in Indian dry deciduous forests (*Hasdeo Arand*) experiences domain shift due to seasonal leaf senescence.

3. **No Field Validation Yet**:
   - Across all modules (`crop`, `forest`, `heat`), analytical metrics are computational evaluations on satellite/reanalysis reference data.
   - In `ml/heat/`, no handheld infrared radiometers, vehicle transects, or Eddy covariance flux towers were deployed in Visakhapatnam to ground-truth skin temperature ($T_{\text{skin}}$) against ambient canopy air temperature ($T_{\text{air}}$).
   - Projected urban forestry cooling benefits (e.g. $-2.5^\circ\text{C}$ local canopy reduction) are algorithmic extrapolations based on continuous TPPI indices, pending physical municipal planting trials.
